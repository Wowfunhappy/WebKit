image decoders

Every file in corpus/ holds the same picture at its own size: the pixel at (x, y) is rgb(x*256/w, y*256/h, 64), opaque in the left half and alpha 128 in the right, dropped where the format cannot carry it. Each row below decodes one encoding and samples four pixels through a canvas. corpus-unspecified-alpha.tiff and corpus-no-extrasamples.tiff hold a fourth sample the file does not describe; both expect libtiff's reading of it, which is associated alpha. Regenerate the corpus with python3 MavericksSupport/tests/image-decoders/make-corpus.py.
