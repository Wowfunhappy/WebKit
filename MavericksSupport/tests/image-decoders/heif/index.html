HEIF decoder

HEIFImageDecoder on the HEIC files LayoutTests carries: a single coded item, and a 2000x800 grid of tiles with a transformative property. Each row checks the decoded size and samples the centre pixel through a canvas: the first file is CSS green, rgb(0,128,0) within HEVC's rounding, and the second a bright green, rgb(0,254,0). Add ?photo=<url> to also show a photograph -- an iPhone HEIC is a grid with an ICC profile -- and judge its orientation and colour by eye.
