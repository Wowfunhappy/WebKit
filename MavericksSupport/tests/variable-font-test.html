Variable web font instancing

Each row asks for one point on an axis and measures the rendered advance width of "HHHHH" at 100px. On a system that cannot instance the font every row measures identically — every weight and width renders as the same master — and that is the failure this checks for. (Absolute widths are not asserted: CSS also pins Amstelvar's opsz axis to the font size, so they are not the raw fvar-default advances.)
