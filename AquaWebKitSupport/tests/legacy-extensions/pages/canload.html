canload.safariextension calls safari.self.tab.canLoad from beforeload handlers, after DOMContentLoaded and from a timer, in an Info.plist Start script (answers in <html data-canload>) and in a Start script added with safari.extension.addContentScriptFromURL (answers in <html data-canload-start>). Every answer carries the global page's running count. Its page.html, opened at the extension's base URI (<html data-base>), calls it from an extension page in a tab (answers in window.__answers).
